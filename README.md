
# MVP сервиса дополнительных услуг для авиапассажиров

Небольшой MVP-экран для выбора дополнительных услуг авиапассажира.

## Функциональность
- Отображение списка дополнительных услуг
- Добавление и удаление услуг (toggle)
- Блок «Итого» со списком выбранных услуг
- Автоматический расчёт общей суммы
- Кнопка «Оформить заказ» (без логики оплаты)
- Адаптивный интерфейс (mobile-first)

## Технологии
- React
- TypeScript
- Vite
- CSS Modules
- Functional Components

## Архитектура
- Состояние выбранных услуг хранится в `App`
- Компоненты:
    - `ServiceList` — список услуг
    - `ServiceCard` — карточка услуги
    - `Summary` — итоговый блок
    - `Button` — переиспользуемая кнопка
- Управление состоянием реализовано через lifting state up
- Возможность добавления и удаления услуг реализована через toggle-логику

## Адаптивность
- Mobile-first подход
- На мобильных устройствах элементы располагаются в одну колонку
- На десктопе — две колонки (список услуг и блок «Итого»)
